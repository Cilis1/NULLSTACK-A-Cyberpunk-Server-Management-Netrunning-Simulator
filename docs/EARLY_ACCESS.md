# Back Room: early-access scenario

This intentionally small standalone scenario (windowed on Windows, terminal-based on Linux) is a first playable slice, not the campaign or M0–M9 completion. You start with 800 credits, one server and a two-unit circuit. Each successful action is one day; rent and equipment overhead are charged after the action. Host to gain income and reputation, buy servers and circuit capacity, cool or repair the rack, or attempt risky intrusions. The Windows game window shows actions and objectives; on Linux, `help` explains the commands and exact victory and loss conditions.

Only hosting wears the rack; cooling reduces that wear. This is an abstract rule, not the physical simulation in the design. Intrusion is a single seeded risk roll, not the planned network minigame. Heat does not decay except through `laylow`. There are no effects or audio. The scenario has no persistent save, settings or mods. The Windows installer is documented separately. Its hardcoded rules are temporary; the planned data-driven content architecture is not implemented.
