# Roadmap

The brief's launch scope is multi-year; this roadmap distinguishes planned work from delivered code. An experimental terminal scenario is available as a separate early-access slice; it does not constitute completion of M0–M9. Each milestone requires a runnable build, tests and documentation before advancing. Release tags, demo GIFs and public CI are release operations, not assumed to exist.

- **M0 Foundation (in progress):** standalone deterministic core, command/event primitives, persistence boundary, headless harness, build and CI scaffolding.
- **M1 Window and shell:** SDL/OpenGL/ImGui workstation, command shell and accessible settings.
- **M2 Physical:** facility/rack construction, power, heat, wear and hardware market.
- **M3 Logical and economy:** resource scheduling, services, contracts and finances.
- **M4 Net:** discovery, tactical intrusion and abandoned infrastructure.
- **M5 Threat and defense:** law, raids, incoming attacks and defenses.
- **M6 Progression:** research, tech tree and legacy.
- **M7 World:** factions, crew, narrative and modes.
- **M8 Polish:** content, accessibility, audio, balancing and performance.
- **M9 Ship:** signed distribution, updater, installer and release assets.

Do not market later milestones as implemented until their acceptance criteria have been verified. A milestone tag requires successful cross-platform CI and a recorded demo; local tests alone are not sufficient.
