# Third-party software and assets

- **SQLite** 3.54.0, public domain (https://sqlite.org/copyright.html), via the pinned [gittiver/sqlite3-amalgamation](https://github.com/gittiver/sqlite3-amalgamation) source mirror. The mirror's BSD 3-Clause license is included in `third_party/licenses/sqlite-amalgamation-BSD.txt`. CMake may instead use a system SQLite installation.

No third-party fonts, audio or artwork are bundled. Future dependencies and assets must be documented with license and source before distribution.
